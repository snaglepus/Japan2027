# Japan 2027

A self-contained HTML itinerary for a family winter trip to Japan, 30 Jan to 13 Feb 2027.

Snow, onsen and slow cities: two weeks through the Japan Alps and the old towns of
Honshu, from ski-town hot springs to a prestige soak beneath Mt Fuji, finishing in Tokyo.

## View it

Published with GitHub Pages: https://snaglepus.github.io/Japan2027/

The page is a single, fully self-contained `index.html`. Fonts load from Google Fonts,
photos from Wikimedia Commons, and the route maps open in Google Maps or Google Earth.
